# 📊 Statistics for Data Science

Welcome to my **Statistics for Data Science** repository!  
This is a collection of detailed notes and learning resources that I’ve compiled while exploring and strengthening my understanding of statistics, which plays a crucial role in Data Science and Machine Learning.

This repository is designed for learners like me — curious, self-driven, and eager to explore concepts from the basics to advanced topics, with practical examples and clear explanations.

---

## 🚀 About This Repository

This repository contains notes covering fundamental and advanced statistical concepts that are essential for anyone aiming to build a strong foundation in data science. Whether you are a student, beginner, or someone revisiting statistical concepts, you’ll find this helpful!

All notes are organized in a way that explains both *what* and *why*, helping learners to not just memorize but understand and apply concepts confidently.

---

## 📂 Topics Covered

### 1️⃣ Descriptive Statistics  
Covers the techniques used to summarize, describe, and visualize datasets. Topics include:  
✔ Measures of Central Tendency  
✔ Measures of Dispersion  
✔ Data Visualization  
✔ Implementation with practical examples  

### 2️⃣ Probability Distributions  
A comprehensive collection of probability theories and distributions that help in understanding uncertainty and randomness in data. Topics include:  
✔ Probability Mass Function (PMF) & Probability Density Function (PDF)  
✔ Normal Distribution  
✔ Binomial Distribution  
✔ Poisson Distribution  
✔ Bernoulli Distribution  
✔ Continuous & Discrete Distributions  
✔ Standard Normal Distribution  

### 3️⃣ Inferential Statistics  
Focuses on making predictions, estimations, and hypothesis testing from sample data to generalize conclusions about a population. Topics include:  
✔ Estimation Techniques  
✔ Hypothesis Testing  
✔ Confidence Intervals  
✔ t-test, z-test  
✔ F-test & ANOVA  
✔ Chi-Square Test  
✔ Bayes Theorem and Applications
